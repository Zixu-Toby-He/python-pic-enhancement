# python-pic-enhancement

一个基于 NumPy、OpenCV 和 PyQt5 的可视化图像增强链路编辑模块。它将普通的 Python 图像处理函数封装为可配置的“增强工具”，允许用户在界面中组合多个工具、实时查看处理效果，并将确认后的链路重复应用到其他图像。

该模块主要面向图像标注、机器视觉预处理和算法效果验证等场景。项目代码及公开接口使用中文命名。

## 功能特性

- 使用可视化界面添加、展开、配置和删除增强工具。
- 增强链路按照界面中从上到下的顺序执行。
- 可按需组合多个增强工具，链路过长时使用垂直滚动条浏览。
- 左侧效果图实时展示临时链路的处理结果。
- 参数支持数值框、滑块以及可调节的上下限。
- “确认”提交本次配置，“取消”丢弃本次修改，正式链路不会被临时修改污染。
- 可以更换预览图，而不改变已经确认的增强链路。
- 同一套增强链路可重复应用到多张 BGR 图像。

## 内置增强工具

| 工具 | 参数 | 作用 |
| --- | --- | --- |
| 线性拓展 | `上限`、`下限` | 将灰度区间裁剪后线性映射到 `0～255`；上下限传反时会自动交换，相等时保持原图不变。 |
| 区间蒙版 | `上限`、`下限` | 保留灰度位于指定区间内的像素，将区间外像素设为黑色。 |
| 左右边界 | 无 | 使用水平方向差分卷积核提取左右方向的边界。 |
| 上下边界 | 无 | 使用垂直方向差分卷积核提取上下方向的边界。 |
| 四向边界 | 无 | 使用斜向差分卷积核提取综合方向边界。 |

## 环境要求

- Python 3.10 或更高版本。类型标注中使用了 `X | None` 语法。
- NumPy
- OpenCV Python
- PyQt5

安装依赖：

```bash
python -m pip install numpy opencv-python PyQt5
```

当前项目已在 Python 3.12、PyQt5 5.15、NumPy 2.x 和 OpenCV 5.x 环境中验证。其他兼容版本通常也可以运行。

## 快速开始

在项目根目录运行：

```bash
python main.py
```

示例程序的执行流程如下：

1. 读取 `图片/1.jpg` 和 `图片/2.jpg`。
2. 使用第一张图片创建 `增强管理器` 并打开参数设置窗口。
3. 将效果预览图更换为第二张图片，再次打开设置窗口。
4. 使用最终确认的增强链路分别处理两张图片。
5. 使用 OpenCV 窗口显示处理结果。

参数设置窗口是模态窗口：必须先确认或取消当前窗口，程序才会继续执行。最终出现两个 OpenCV 结果窗口后，让其中一个窗口获得焦点并按任意键即可结束 `cv2.waitKey()`，随后示例程序退出。

## 界面操作

主区域由左侧“效果图”和右侧“增强链路”组成，宽度比例约为 `7:3`。

### 添加工具

1. 点击链路底部的“输出（添加优化工具）”。
2. 在展开的工具列表中选择一种增强工具。
3. 新工具会追加到链路末尾。

### 调整参数

点击链路中的工具按钮可展开设置区域。对于带参数的工具，每个参数行包括：

- 当前参数值；
- 最小允许值；
- 参数滑块；
- 最大允许值。

当前值与滑块双向联动。修改上下限时，控件会自动保证最小值不大于最大值。参数发生变化后，左侧效果图会立即刷新。

### 删除或收起工具

- 点击“删除该工具”会从临时链路中移除当前工具。
- 点击“收起”会恢复为工具摘要按钮。
- 工具摘要最多展示两个参数及其当前数值。

### 确认与取消

- 点击“确认”：将临时链路深拷贝到正式输出链路，后续调用 `图像增强()` 时使用新配置。
- 点击“取消”：放弃窗口内的增删和参数修改，恢复打开窗口之前的正式链路。

## 基本 API

### 创建管理器

```python
import cv2
import numpy
import PyQt5.QtWidgets

import 图像增强

应用实例 = PyQt5.QtWidgets.QApplication([])

图像 = cv2.imread("input.jpg", cv2.IMREAD_COLOR)
增强管理器 = 图像增强.增强管理器(图像)
```

传入的图例必须满足以下条件：

- 类型为非空 `numpy.ndarray`；
- 形状为 `(高度, 宽度, 3)`；
- 通道顺序为 OpenCV 使用的 BGR；
- 推荐使用 `uint8` 数据。

不符合三通道 BGR 形式的图例会触发 `ValueError`。

### 打开设置窗口

```python
增强管理器.设置参数()
```

该调用会阻塞到用户点击“确认”、点击“取消”或关闭窗口。方法内部使用 `QDialog.exec_()`，因此调用前必须已经创建 `QApplication`。

### 更换效果预览图

```python
增强管理器.更换效果图例(另一张图像)
```

这只更换设置窗口使用的效果预览图，不会清空或重新创建已经确认的输出链路。

### 应用增强链路

```python
结果图像 = 增强管理器.图像增强(原始图像)
```

正式输出链路为空时返回传入的图像；链路非空时依次调用每个增强工具。为了避免意外共享数据，如果调用方还需要保留原始数组，建议传入 `原始图像.copy()`，或者确保所使用的工具不会原地修改输入。

完整示例：

```python
import sys

import cv2
import PyQt5.QtWidgets

import 图像增强


if __name__ == "__main__":
    应用实例 = PyQt5.QtWidgets.QApplication(sys.argv)

    原始图像 = cv2.imread("input.jpg", cv2.IMREAD_COLOR)
    if 原始图像 is None:
        raise FileNotFoundError("无法读取 input.jpg")

    管理器 = 图像增强.增强管理器(原始图像)
    管理器.设置参数()

    结果图像 = 管理器.图像增强(原始图像)
    cv2.imshow("result", 结果图像)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

    sys.exit(0)
```

这里不需要在最后调用 `应用实例.exec_()`：设置窗口已经通过 `QDialog.exec_()`运行过自己的模态事件循环。所有 Qt 窗口都关闭后再次启动 `QApplication.exec_()`，可能导致没有可见窗口但进程仍不退出。

## 添加自定义增强工具

增强工具采用“函数工厂”形式：外层函数声明可配置参数并返回真正处理图像的内层函数。外层函数名必须以 `获取图像增强函数_` 开头，后缀会成为界面显示的工具名称。

例如，添加一个亮度偏移工具：

```python
import numpy


def 获取图像增强函数_亮度调整(偏移=0):
    def 增强函数(
        图片: numpy.ndarray,
        同图灰度图: numpy.ndarray | None = None,
        偏移=偏移,
    ):
        临时图像 = 图片.astype(numpy.int16) + 偏移
        return numpy.uint8(numpy.clip(临时图像, 0, 255))

    return 增强函数
```

然后在 `增强管理器.__init__()` 的工具注册列表中加入该工厂函数：

```python
for 函数 in [
    工具函数.获取图像增强函数_线性拓展,
    工具函数.获取图像增强函数_亮度调整,
    # 其他工具……
]:
    ...
```

工具封装会通过 `inspect.signature()` 读取外层函数的参数：

- 参数名将直接显示在设置界面中；
- 有默认值时使用默认值；
- 没有默认值时初始值为 `0`；
- 当前界面使用 `QSpinBox`，因此可配置参数应为整数；
- 内层增强函数必须接收 BGR 图像，并返回形状兼容的 `numpy.ndarray`。

可选的 `同图灰度图` 参数是为了让需要灰度判断的算法复用已经计算的灰度图。它可以是二维灰度数组，也可以是三通道灰度数组。不需要灰度图的工具可以忽略该参数。

## 使用限制与注意事项

- 当前工具只能追加到链路末尾或从链路中删除，暂不支持拖拽排序。
- 参数编辑器目前只支持整数参数。
- 所有界面操作应在创建 `QApplication` 的主线程中进行。
- 图像通道按 BGR 解释；若数据来自 Pillow 等 RGB 图像源，应先转换通道顺序。
- `cv2.waitKey(0)` 会一直等待键盘输入。这是 OpenCV 窗口的正常行为，不是程序卡死。
